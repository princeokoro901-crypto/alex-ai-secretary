# Alex v2.8 — Agent Learning & Performance

Performance records observable agent outcomes: completion, failure, uncertainty, verification, confidence, duration, budget, and per-tool history.

Performance is advisory only. It never grants a capability, permission, trust level, or mission authority. Recommendations only consider agents that already possess the requested tool.

Flow:

`Execution -> Performance Event -> Profile -> Tool-specific metrics -> Advisory recommendation`

Metrics include success rate, verification rate, confidence, average duration, budget spent, and sample size.
