# Alex v2.9 — Agent Selection & Task Routing

v2.9 connects task requirements with the workforce and performance advisory layer.

Routing order:
1. Task type and required tools
2. Registered workforce membership
3. Agent availability
4. Mission assignment, when a mission is supplied
5. Mission tool policy, when a mission is supplied
6. Performance history as an advisory score

Performance never grants tools, permissions, trust, budget, or mission authority.
A route is only a recommendation; execution re-checks all boundaries at the runtime gate.
