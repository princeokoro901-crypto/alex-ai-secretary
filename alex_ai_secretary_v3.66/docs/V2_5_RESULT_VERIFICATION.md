# Alex v2.5 — Agent Result Verification & Provenance

v2.5 adds a verification layer so agent outputs carry evidence, verification state, unresolved questions, and provenance.

Principles:
- Agent output is not automatically truth.
- Verification does not grant additional authority.
- Evidence is referenced explicitly.
- Unresolved questions prevent a result from being marked verified.
- Provenance records the runtime, agent, and tool that produced the result.
